### Operation

-	Make sure the PDMS insert is not present!!
-	Connect power supply
-	Press ON/OFF button to ON position (| symbol)
-	The device will “home” all the actuators and move them to the centre
-	Load the PDMS insert
-	Select frequency (Hz)
-	Select stretch (mm)
-	Optional - Press stretch button to change mode (alternative, simultaneous…)
-	Press frequency button to start
